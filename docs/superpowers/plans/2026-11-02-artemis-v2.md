## Tâches

### Task 1 — Docs et positionnement
- `docs/benchmark-2026-11.md` (synthèse du benchmark), section V2 de la spec, README (positionnement, rails, tarifs, PCI), `docs/deploiement.md` (Revolut accord écrit, Qonto lecture/gel, SASU, Stripe meter).

### Task 2 — Nouvelle grille et dépassement
- `PLAN_LIMITS` : ajouter `agency`, nouveaux prix/quotas, champs `overageCents` (25), `slack`, `quorum`, `subscriptions`, `clients`, `auditExport`.
- Migration `0005` : `alter type plan add value 'agency'`, tables suivantes (V2) groupées.
- `createCardRequest` : plan payant au-delà du quota → accepté, `usage_counters.overage` incrémenté, événement Stripe meter `artemis_mandate_overage` (si `STRIPE_METER_OVERAGE` défini) ; Sandbox → `quota_exceeded`.
- Tests : quota sandbox refusé ; builder au-delà du quota accepté + overage compté + appel meter.

### Task 3 — Lien éphémère émetteur (PAN hors Artemis)
- Réglage org `card_delivery` : `issuer_link` (défaut) | `direct`. `get_card_for_checkout` / `POST /v1/card-requests/:id/reveal` : en `issuer_link`, renvoie `{ delivery: 'issuer_link', checkout_url, expires_at }` ; le PAN n'est jamais lu par Artemis.
- Lien : jeton 32 o, haché dans `kv` (10 min), consommé une fois. Page publique app `/c/:token`.
- API publique `GET /v1/reveal-links/:token` (métadonnées : provider, last4, montant, marchand), `POST /v1/reveal-links/:token/session` : Stripe → crée une clé éphémère Issuing (`POST /v1/ephemeral_keys`, `issuing_card`, `nonce`) et renvoie `{ ephemeralKeySecret, cardId, publishableKey }` ; Sandbox → détails simulés ; marque la carte remise et le lien utilisé.
- `direct` reste possible (Stripe/Revolut) ; Qonto → `card_not_ready` avec affichage humain.
- Tests : lien à usage unique, expiré, jamais de PAN dans la réponse en mode `issuer_link`, mode `direct` inchangé.

### Task 4 — Mode agence
- Table `clients` (org, nom, email facturation, marge %, budget mensuel, statut). `agents.client_id`, `card_requests.client_id`.
- Budget client vérifié comme le budget agent (refus `over_client_budget`).
- Routes `/app/clients` CRUD, `/app/clients/:id/report?month=` (CSV + JSON : achats, marge, total à refacturer), rapport mensuel par client.
- Facturation : clients actifs du mois → meter `artemis_active_client`.
- App : pages Clients (liste, détail, rapport), sélecteur client sur l'agent.
- Tests : budget client, rapport avec marge, limite de plan.

- Cron : gel des agents sans justificatif dans le délai ; alerte.
- Tests pour chacun.
