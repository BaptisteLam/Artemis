# Artemis V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire le SaaS Artemis V1 : site, app PWA, API REST + serveur MCP, moteur de règles, connecteurs bancaires (Sandbox, Stripe Issuing, Qonto, Revolut), facturation par abonnement, back-office — déployable à coût fixe nul.

**Architecture:** Monorepo pnpm/Turborepo. `apps/api` est un Worker Cloudflare (Hono) qui porte toute la logique métier derrière une interface `Store` (implémentation mémoire pour tests/dev, implémentation Supabase pour prod). `apps/app` (React/Vite PWA) et `apps/site` (Astro) sont statiques sur Cloudflare Pages. La logique pure vit dans des paquets testés isolément (`policy`, `connectors`, `shared`).

**Tech Stack:** TypeScript strict, pnpm 9, Turborepo 2, Hono 4, Zod 3, Vitest 2, Playwright, Astro 4, React 18 + Vite 5 + React Router 6, Supabase (Postgres, Auth, Storage), PGlite (tests SQL), @simplewebauthn/server + /browser, Stripe REST via fetch, Resend REST via fetch, Wrangler.

**Spec:** `docs/superpowers/specs/2026-11-01-artemis-v1-design.md`

## Global Constraints

- Aucun numéro de carte complet (PAN) ni CVC en base, dans les logs, l'audit ou les messages d'erreur. Ils ne transitent que dans la réponse de `get_card_for_checkout`.
- Montants : entiers en centimes (`amountCents`), devise ISO 4217 en majuscules. Affichage FR : `49,00 €`, négatif avec vrai signe moins `−42,10 €` (U+2212).
- Jetons d'agent : préfixe `art_live_` (connexion réelle) ou `art_test_` (Sandbox) + 32 octets aléatoires en base64url ; stockés en SHA-256 hex ; affichés une seule fois.
- Mois budgétaire calculé en fuseau `Europe/Paris`.
- Format d'erreur unique : `{ "error": { "code": string, "message": string } }`.
- Plans : `sandbox` 0 € (1 agent, Sandbox seulement, 50 demandes/mois) · `builder` 19 € (3 agents, 1 banque, 100) · `team` 49 € (15 agents, 2 banques, 1 000, FEC) · `business` 149 € (illimité, export audit, API REST).
- Défauts de politique : `card_ttl_minutes` 30 (max 10 080), `request_ttl_minutes` 30, limite de débit 60 req/min par agent.
- Coût fixe nul : uniquement offres gratuites Cloudflare, Supabase, Resend ; aucune dépendance payante.
- Design : tokens Lucent renommés Artemis (`--ar-*`), Geist / Geist Mono, sentence case, pas d'emoji, glyphes autorisés `↳ → · •`.
- Copie FR ; signature « Vos agents paient. Vous gardez le dernier mot. »
- Factures : mention « TVA non applicable, art. 293 B du CGI ».
- Commits : messages en français, conventionnels (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).

**Écart assumé vs spec §6.3 :** l'app lit ses données via `apps/api` (pas de lecture directe Supabase+RLS côté navigateur ; RLS reste activée en défense). Raison : un seul chemin d'autorisation et des tests E2E sans Supabase grâce au `MemoryStore`. Un mode d'authentification `dev` (en-tête `Authorization: Dev <email>`) n'existe que si `AUTH_MODE=dev` et est refusé si `ENVIRONMENT=production`.

## Review Focus

1. **Deux demandes simultanées pour le même agent** dépassant ensemble le budget : une seule doit passer. → test `budget is enforced atomically under concurrency` (Task 9).
2. **Double appel concurrent à `get_card_for_checkout`** : un seul reçoit les identifiants, l'autre `already_revealed`. → test `reveals card details exactly once under concurrency` (Task 9).
3. **Montants envoyés par un LLM en euros décimaux ou en texte** (`49.9`, `"49"`, `-5`) : refus clair `invalid_amount` qui rappelle que l'unité est le centime. → test `rejects non-integer amount with cents hint` (Task 2).
4. **Variantes du nom de marchand** (`Notion Labs Inc.`, `notion.so`) face à une liste blanche `Notion` : correspondance après normalisation. → test `matches merchant variants after normalisation` (Task 6).
5. **Approbation d'une demande expirée, déjà décidée, ou par un `viewer`** : refus (`request_not_pending`, `forbidden`). → test `refuses approval when not pending or not approver` (Task 9).
