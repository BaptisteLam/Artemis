# Intégrations

- `claude-skill/artemis/SKILL.md` : skill Claude (Claude Code, Claude Desktop, API) qui apprend à l'agent à payer via Artemis sans jamais manipuler la carte de l'entreprise. Copier le dossier `artemis` dans `~/.claude/skills/` ou le joindre à un plugin.
- `n8n-nodes-artemis/` : nœud communautaire n8n (à publier sur npm).
- CLI : `packages/cli` (`npx artemis-agents init`).
