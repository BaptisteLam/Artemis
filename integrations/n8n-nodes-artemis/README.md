# n8n-nodes-artemis

Nœud communautaire n8n pour Artemis : demander une carte virtuelle à usage unique validée par un humain, suivre la demande, obtenir le lien de paiement éphémère, annuler, lire le budget.

Installation (n8n auto-hébergé) : Paramètres → Community nodes → `n8n-nodes-artemis`. Publication : `npm run build && npm publish` (compte npm de l'éditeur).
